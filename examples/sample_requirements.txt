# 示例大学硕士学位论文格式要求
# ================================
# 本文件展示了典型学校格式要求文档的写法
# 工具会自动解析此文件并应用格式规则

# 字体要求
中文字体：宋体
英文字体：Times New Roman
标题字体：黑体

# 字号要求
章标题字号：三号（16pt）
节标题字号：四号（14pt）
小节标题字号：小四（12pt）
正文字号：小四（12pt）
图表标题字号：五号（10.5pt）
参考文献字号：五号（10.5pt）

# 行距要求
正文行距：1.5倍
标题行距：1.5倍
参考文献行距：1.25倍

# 段落要求
首行缩进：2字符
对齐方式：两端对齐
章标题对齐：居中
节标题对齐：左对齐

# 页边距
上边距：2.54cm
下边距：2.54cm
左边距：3.17cm
右边距：3.17cm

# 摘要格式
摘要标题字号：三号（16pt），加粗，居中
摘要正文字号：小四（12pt），1.5倍行距
摘要首行不缩进

# 关键词格式
关键词标签："关键词："
关键词标签加粗：是
关键词分隔符：分号（；）

# 参考文献格式
参考文献风格：GB/T 7714
编号方式：顺序编号
悬挂缩进：是

# 图表格式
图标签：图
图编号方式：按章节（图1-1）
图标题位置：图下方
表标签：表
表编号方式：按章节（表1-1）
表标题位置：表上方
表头加粗：是

# 页眉页脚
页眉：显示章名，宋体五号，居中，有下边框
页脚：显示页码，居中
首页不同：是（首页不显示页眉）
奇偶页不同：否

# 页码设置
前置页（摘要、目录）：小写罗马数字（i, ii, iii）
正文：阿拉伯数字（1, 2, 3）

# 目录
目录层级：3级
目录标题：三号黑体居中
目录正文：小四宋体1.5倍行距

# 代码块
代码块保留原始格式：是

# 特殊说明
章标题格式："第一章 绪论"、"第二章 文献综述" 等
节标题格式："1.1"、"1.2" 等
小节标题格式："1.1.1"、"1.1.2" 等
