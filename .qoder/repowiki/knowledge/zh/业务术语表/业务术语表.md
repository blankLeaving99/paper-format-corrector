### 格式预设
- 定义：预定义的论文格式规范集合，包含字体、字号、行距、页边距、标题层级等完整排版规则。项目内置 38 种预设，覆盖 IEEE、Nature、Science、APA 等国际期刊以及清华、北大、浙大等国内高校毕业论文格式要求。每个预设以 YAML 文件形式存储在 presets/ 目录下。
- 别名：preset、格式模板

### 需求文档驱动
- 定义：通过解析学校或期刊提供的格式要求文档（.docx/.txt/.md），自动提取排版规则并应用到目标论文的功能特性。支持自然语言描述和结构化表格两种格式的需求文档。
- 别名：requirement-driven、需求解析

### LLM 智能解析
- 定义：利用大语言模型（OpenAI/Anthropic/Ollama）理解复杂的排版需求描述，将自然语言格式要求转换为机器可读的格式规则的能力。支持多语言输入和模糊需求理解。
- 别名：AI 解析、智能需求解析

### 质量评分
- 定义：对矫正后的论文文档进行格式规范性打分（0-100分）的功能，评估字体、字号、行距、对齐、缩进、页边距等格式要素是否符合预设标准。
- 别名：格式评分、quality score

### 差异对比
- 定义：生成矫正前后文档的 HTML 格式对比报告，高亮显示所有格式修改的位置和内容变化，便于用户审查和确认修改效果。
- 别名：diff report、对比报告

### 图表编号
- 定义：自动为论文中的图、表、公式进行连续编号，支持按章节编号（如"图1-1"、"表2-3"）、交叉引用更新等功能，确保编号的一致性和准确性。
- 别名：figure numbering、table numbering

### 参考文献格式化
- 定义：自动将参考文献列表转换为指定格式（GB/T 7714、IEEE、APA 等），统一作者名、标题、期刊名、卷期号、页码等字段的格式和标点符号。
- 别名：reference formatting、citation style

### 任务队列
- 定义：支持大量批处理任务的异步处理机制，提供任务提交、状态查询、进度跟踪、结果获取等完整生命周期管理。适用于批量处理多个论文文档的场景。
- 别名：task queue、batch processing

### 协作模板库
- 定义：多人共享的模板管理系统，支持模板的上传、下载、分享、权限控制等功能。本地使用 SQLite 存储，远程可通过 SQLAlchemy 连接其他数据库。
- 别名：collaborative templates、template sharing

### 云端模板更新
- 定义：自动从远程服务器同步最新模板的功能，支持增量更新、冲突解决、版本管理等特性，确保团队成员使用最新的格式规范。
- 别名：template sync、cloud update

### PDF 反向学习
- 定义：从 PDF 文档中逆向提取格式规则的功能，支持原生 PDF（文本型）和扫描 PDF（图像型）两种类型，通过 OCR 技术处理扫描件。
- 别名：PDF reverse learning、style extraction from PDF

### LaTeX 导出
- 定义：将 DOCX 论文转换为 LaTeX (.tex) 格式的功能，优先使用 pandoc 进行高质量转换，不可用时降级为纯文本提取 + LaTeX 模板包装。
- 别名：LaTeX export、DOCX to LaTeX

### Word 插件
- 定义：Microsoft Word 的 Office 插件，提供嵌入式的论文格式矫正功能，用户可以直接在 Word 中使用预设模板进行格式处理。
- 别名：Word addin、Office plugin

### 多语言字体规则
- 定义：根据文档语言自动检测和切换字体配置的机制，支持中文、英文、日文、韩文等多种语言的字体映射和运行时覆盖。
- 别名：multilingual fonts、language-aware fonts

### 封面生成
- 定义：根据论文元数据（标题、作者、导师、专业、日期等）自动生成符合格式要求的论文封面页的功能。
- 别名：cover page generation、title page

### 目录生成
- 定义：自动识别文档标题层级并生成/更新目录的功能，支持多级标题、页码对齐、超链接跳转等特性。
- 别名：TOC generation、table of contents

### 插件系统
- 定义：支持第三方扩展的自定义矫正规则机制，允许开发者编写 Python 插件来添加新的格式处理逻辑。
- 别名：plugin system、custom rules
