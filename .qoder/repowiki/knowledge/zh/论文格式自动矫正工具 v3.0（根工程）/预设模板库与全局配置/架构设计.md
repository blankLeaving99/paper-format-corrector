本模块为纯数据层，不包含任何可执行代码，由上层 CLI/GUI 通过路径解析加载：
- `presets/templates_index.yaml` 是元索引，按 `categories` 分组列出所有模板的 id、文件映射、来源、验证状态等，供 `--list-presets` 和 GUI 下拉框消费。
- `presets/*.yaml` 每个文件对应一个具体模板（如 `tsinghua.yaml`、`ieee.yaml`），定义该模板下的字体、字号、页边距、标题层级、参考文献样式等格式规则；`doc_templates/` 下为通用办公文档模板（合同、会议纪要等）。
- `config/config.yaml` 是默认全局配置，提供语言/字体、`format_rules`（正文、摘要、关键词、图表、公式、页眉页脚、目录、自动检测正则、并行度等）以及云端同步开关，被程序启动时作为基线加载。
- `config/updater.yaml` 单独维护远程模板仓库地址、本地缓存目录与检查间隔，与主配置解耦以便独立更新。
依赖方向单向：CLI/GUI → 读取 YAML → 注入到格式化流水线；本模块不反向依赖任何 Python 包。
