- 每个预设模板以独立的 `<id>.yaml` 文件命名，并通过 `templates_index.yaml` 中的 `id` + `file` 字段建立索引映射。
- 模板条目在索引中统一包含 `id`、`name`/`name_en`、`file`、`category`、`source`、`year`、`verified`、`description` 等固定字段，便于 GUI 渲染与校验。
- 分类采用英文 key（如 `chinese_university`、`international_conference`、`citation_style`）搭配中文 `name`/`description` 的双语文案模式。
- 全局配置使用嵌套 YAML 键（`template.*`、`language.*`、`format_rules.*`、`auto_detect.*`、`concurrency.*`）组织不同子系统，新增规则时保持同级缩进风格一致。
- 自动检测规则全部以 `*_pattern` 结尾的正则字符串形式声明，集中在 `auto_detect` 节点下，避免硬编码到代码中。
