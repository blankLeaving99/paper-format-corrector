本模块是面向用户的三个独立入口，均依赖 `app.PaperFormatCorrector` 作为编排器，不直接操作文档树：
- `__main__.py` 仅转发到 `cli.main()`，使 `python -m paper_format_corrector` 可直接运行。
- `cli.py` 基于 `argparse` 实现子命令模式（`scan/correct/learn/template/batch/report`）与向后兼容的平铺参数模式；每个子命令函数负责解析参数并调用 `PaperFormatCorrector` 或 `BatchCorrectionService` 等上层服务。
- `gui.py` 基于 Gradio 构建 Web 界面，通过全局 `_ai_sessions` 字典管理 AI 对话会话，所有业务逻辑以顶层函数形式暴露给 Gradio 组件回调。
- `desktop_gui.py` 基于 tkinter + ttk 构建桌面应用，封装为 `PaperFormatDesktopApp` 类，使用自定义 `DropFileEntry`/`MultiDropFileEntry` 组件支持拖拽，并通过 `threading.Thread` 在后台线程执行耗时任务，用 `root.after(0, ...)` 回写 UI。
- 三者共享同一套配置加载、模板库（`TemplateRepository`）、样式工作台（`style_workbench`）和质量评分能力，GUI 与 CLI 的差异仅在于参数绑定与结果展示方式。
