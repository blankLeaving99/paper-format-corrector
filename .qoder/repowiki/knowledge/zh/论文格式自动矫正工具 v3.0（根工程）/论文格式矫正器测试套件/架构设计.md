测试采用扁平单包结构（tests/），通过 conftest.py 集中提供共享 fixture：`project_root`、`config`、`template_path`、`sample_paper_path`、`thesis_paper_path`、多类 `requirement_*_path`（自然语言/表格/mixed/docx）以及 `thesis_requirement_path`，所有 fixture 均基于 `tmp_path` 生成临时文件，避免污染真实资源。

- 依赖注入：每个测试文件在顶部执行 `sys.path.insert(0, .../src)` 以直接 import `paper_format_corrector.*`；部分测试使用函数内局部 import 延迟加载被测模块。
- 组织方式：按功能域拆分到独立 test_*.py 文件（如 template_repository、rule_parser、llm_parser、pdf_style_extractor、task_queue 等），同时保留 test_basic.py 做轻量 import 冒烟检查，test_cli_integration.py 用 class 分组组织集成用例。
- 外部依赖隔离：大量测试使用 `tmp_path` 构造虚拟 docx/yaml/db 路径，不依赖真实文件系统；对 LLM/网络相关能力仅断言接口存在或走离线回退路径。
- 运行入口：标准 pytest 发现机制，无自定义 runner 或脚本。
