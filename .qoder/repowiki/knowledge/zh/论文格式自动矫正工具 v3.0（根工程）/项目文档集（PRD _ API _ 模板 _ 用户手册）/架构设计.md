本模块为无代码的 Markdown 文档目录，按读者角色与用途拆分为四个独立文件：
- `PRD.md`：面向产品/架构的全量需求文档，包含功能清单、技术栈、模块架构图（run.py → cli/gui/desktop_gui/app → core/parsers/handlers/quality/generators/infra）、处理管线、配置优先级与 v3.0/v4.0 路线图。
- `api_guide.md`：面向集成方的 REST API 参考，覆盖启动方式（uvicorn / 直接运行）、全部端点（/health、/correct、/scan、/plan、/learn、/batch、/templates、/presets、/reports、/university-import/*）、错误码、限流与部署建议，并提供 curl / requests / fetch 调用示例。
- `template_guide.md`：面向模板作者与高校贡献者的 YAML 模板规范，定义 `format_rules.*` 与 `auto_detect.*` 字段字典、命名约束、校验方法（API `/templates/validate`、CLI `template list/info/export`、Python `load_preset`），并附完整注释示例。
- `user_guide.md`：面向终端用户的安装指南（exe / run.py / pip extras）、Web GUI（Gradio）与桌面 GUI（tkinter + tkinterdnd2）操作说明、CLI 子命令参考与 FAQ。
四个文件相互引用但不耦合，共同构成该 Python 包的外部契约与使用约定。
