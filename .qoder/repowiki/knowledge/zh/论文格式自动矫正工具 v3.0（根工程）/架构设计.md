根目录承担「零依赖启动 + 多模式分发」的编排职责：
- 运行期：run.py 先检测/创建 .venv 并校验 python-docx、pyyaml、lxml、Pillow 四个核心依赖，随后通过 tkinter 弹窗让用户选择桌面 GUI（tkinterdnd2）或 Web GUI（gradio），再动态 from paper_format_corrector.desktop_gui / gui 导入对应入口；CLI 则通过 pyproject.scripts 暴露 paper-fmt / paper-correct 两个命令。
- 构建期：build.py 用 PyInstaller 生成单文件 exe，仅打包 src/config/template/presets/run.py/requirements.txt，不携带 .venv，使分发包在目标机器上首次运行仍走 run.py 的自安装流程。
- 配置期：pyproject.toml 集中声明 [project.dependencies] 与 [project.optional-dependencies]（pdf/html/pdf-import/gui/drag-drop/all/dev/sync），被 run.py 的 _DEPS/_OPTIONAL_DEPS 列表与 tests 的 pytest 环境共同消费，形成「单一来源」的依赖契约。
- 数据层：presets_and_templates 下的 YAML 模板由 core 引擎在运行时加载，examples_and_data 提供对照样本供 tests 端到端验证，reference_material 作为第三方源码参考不参与运行时路径。
