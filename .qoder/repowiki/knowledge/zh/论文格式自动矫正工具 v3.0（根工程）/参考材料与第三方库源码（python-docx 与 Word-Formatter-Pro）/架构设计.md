本模块为只读参考目录，包含两个独立子项目：
- `python-docx/`：完整的 python-docx 发行版源码，按功能分层组织——`src/docx/opc` 实现 OLE Package 容器读写、`src/docx/oxml` 基于 lxml 的 XML 映射层、`src/docx/parts` 将 OPC Part 类型映射到具体解析器、`src/docx/text`/`table`/`styles`/`image` 等提供高层 API；`features/` 使用 behave BDD 行为驱动测试，`docs/` 由 Sphinx 生成文档，`ref/rnc` 与 `ref/xsd` 存放 ISO/IEC 29500 与 DML/PPTX/XLSX 的 RNC/XSD 规范文件。
- `Word-Formatter-Pro/Word-Formatter-Pro/skills/doc-format/`：以 SKILL.md 为入口的“技能”包，通过 `scripts/wfp_cli.py` 暴露 CLI，内部 `wfp_core.py`/`wfp_config.py`/`wfp_version.py` 分别承载核心格式化逻辑、配置加载与版本信息，`references/` 下 cli-reference/config-reference/formatting-rules.md 供 Agent 按需查阅；顶层 `wfp.py`/`wfp_gui.py` 是独立的桌面 GUI 应用，与 skill 脚本解耦。
依赖方向：skill 脚本仅调用自身 scripts 内的模块，不反向依赖 python-docx 源码；两者在本仓库中并列存放，无相互 import。
